Cómo usar los archivos en Python

ZIP de PNG: contiene una carpeta por clase (PARE/, FLECHA/, …) y un labels.csv. Cada archivo se llama CLASE_sesion_###.png: trazo negro sobre fondo blanco, 200 × 200 px.

NumPy: cada posición de y corresponde a la misma posición de X.

import numpy as np
import matplotlib.pyplot as plt

X = np.load("X.npy", allow_pickle=False)
y = np.load("y.npy", allow_pickle=False)

print(X.shape, X.dtype)  # (N, 200, 200), uint8
print(y.shape, y.dtype)  # (N,), <U9
plt.imshow(X[0], cmap="gray", vmin=0, vmax=255)
plt.title(f"Señal: {y[0]}")
plt.axis("off")
plt.show()

# Etiquetas numéricas para entrenar
CLASES = ["PARE", "FLECHA", "PROHIBIDO", "PEATON", "SEMAFORO"]
y_num = np.array([CLASES.index(c) for c in y])
X_normalizado = X.astype(np.float32) / 255.0

En X.npy se exporta el canal alfa del lienzo: fondo = 0, trazo = 255. Las guías visuales no forman parte de las imágenes.
